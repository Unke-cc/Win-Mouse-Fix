# Win Mouse Fix 0.1.7 发布说明

适用版本：`0.1.7`。安装包：`dist/WinMouseFix-Setup-0.1.7.exe`。

## 相对用户可见的变化

### 设置窗口

- 窗口宽 480 px，内容 440 px；切换页面左上角不动，只改高度。
- 通用、滚动、关于无整页滚动条。
- 状态改为底部深色 HUD 胶囊，去掉底部蓝条。
- 通用页标题为「启动 Win Mouse Fix」；登录运行和全屏暂停固定开启，界面不再提供开关。
- 按钮页：150 px 加号录入、130 px 左列贯通分割线、无系统选中蓝。
- 恢复默认值窗口无「推荐」字样；双击速度显示「快 · 150 ms」。

### 滚轮与手势

- 滚动页三选一：Windows 原生、平滑流动、惯性飞轮。
- 原生模式不接管滚轮速度；未按映射键时不注册全局滚轮热键。
- 按住中键或侧键的滚轮手势在按钮页配置，不再用 Ctrl/Alt/Shift/Win 拦截滚轮。
- 左键、右键不能作为手势键。
- 惯性：同向 ≥4 格且平均间隔 < 60 ms；阻尼 0.72，低于 0.25 停止。
- 快滚加 `OnError` 和热键频率 2000/2s，避免核心退出。

### 常驻

- 无按键时位移定时器关闭。
- 设置窗口隐藏或进托盘时修剪工作集。
- 登录运行：`WinMouseFix.Tray.exe --background`。

## 已知限制

- 映射很多时列表没有最大高度，矮屏幕可能超出窗口。
- 便携版登录运行登记使用托盘绝对路径。
- 多显示器全屏可能误暂停。
- 无法按设备来源区分触控板和鼠标；原生模式靠不接管滚轮来放行触控板。
- 仓库 `config/default.json` 仍为 `takeOverWheel: true`。界面把该组合显示为平滑流动；需要系统原手感时在滚动页选「Windows 原生模式」。

## 安装

覆盖安装保留 `%AppData%\WinMouseFix`。便携版使用 `dist/app/`。
