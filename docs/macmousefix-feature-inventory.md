# MacMouseFix 3.0.8 功能盘点与 Windows 映射

本文根据 MacMouseFix 3.0.8 整理用户功能和交互，作为 Win Mouse Fix `0.1.7` 的对照。以本表「Win Mouse Fix」列为准。

## 1. 视图结构与模块映射

| 页面 | MacMouseFix 核心功能 | Win Mouse Fix 0.1.7 |
|---|---|---|
| General | 总开关、菜单栏常驻、更新检查、预览版本 | 「启动 Win Mouse Fix」总开关；登录运行与全屏暂停固定开启（无界面开关）；双源更新在关于页 |
| Buttons | 移入新增手势、动作下拉、列表管理 | 150 px 加号录入区、130 px 左列贯通表格；手势键仅中键和侧键 |
| Scrolling | 平滑程度、触控板模拟、方向、速度 | 三选一：原生、平滑、惯性；反向；速度滑块。无键盘修饰键拦截滚轮 |
| Pointer | 灵敏度与加速度（源码默认隐藏） | 交给 Windows 鼠标设置，应用内不接管指针 |
| About | 版本、协议、主页、更新 | 版本、GitHub/Gitee、许可 |

## 2. 手势触发与动作

录入区捕获后自动新增映射。触发：点按、连按、按住、按住滚动、按住拖动。左键、右键拒绝录入。

动作包括前进后退、任务视图、显示桌面、开始菜单、左右虚拟桌面、音量、缩放、标签页、网页滚动导航、自定义快捷键。

## 3. 物理滚动

- **原生**：不挂全局滚轮热键，系统与触控板保持原样；按住已映射中键/侧键时才临时收滚轮做手势。
- **平滑**：对机械滚轮步进插值。
- **惯性**：同向连拨满 4 格且平均间隔 < 60 ms 才给阻尼尾（0.72，低于 0.25 停）。
- **手势解耦**：按住中键/侧键时滚轮走按钮映射，不走平滑/惯性。

## 4. 后台

核心常驻读 JSON；设置窗口按需。配置变更后约 250 ms 热载。独立托盘管核心和单实例。设置窗口关闭后可轻量运行并修剪工作集。
