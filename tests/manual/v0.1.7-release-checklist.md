# Win Mouse Fix 0.1.7 发布验收检查清单

适用版本：`0.1.7`。外观与本版本交互以本清单为准；功能回归见 [mvp-checklist.md](./mvp-checklist.md)。

## 1. 顶栏与布局

- [ ] **UI-01** 顶栏：通用、按钮、滚动、关于，上图标下文字，激活项为白卡胶囊。
- [ ] **UI-02** 窗口宽 480 px，内容 440 px，切页横向不抖。
- [ ] **UI-03** 切页时左上角不动，只改高度。
- [ ] **UI-04** 通用、滚动、关于无整页滚动条。
- [ ] **UI-05** 保存后底部深色 HUD 胶囊约 2 秒消失，无底部蓝条。

## 2. 按钮页

- [ ] **BTN-01** 录入区高约 150 px，加号，移入微浮，操作时短暂亮蓝。
- [ ] **BTN-02** 表头与数据行分割线在 130 px 贯通。
- [ ] **BTN-03** 点击行无系统选中蓝。
- [ ] **BTN-04** 左键、右键不能录入。
- [ ] **BTN-05** 少量映射时窗口高度收紧，无大块空白页脚。

## 3. 滚动页

- [ ] **SCR-01** 原生：不改变系统滚轮速度，未按映射键时触控板零干预。
- [ ] **SCR-02** 平滑：机械滚轮顿挫减弱。
- [ ] **SCR-03** 惯性：慢速即停；极速连拨后有阻尼尾。
- [ ] **SCR-04** 无 Ctrl/Alt/Shift/Win 滚轮拦截输入框。
- [ ] **SCR-05** 按住侧键/中键滚动走按钮手势，不走惯性尾巴。

## 4. 弹窗与通用页

- [ ] **POP-01** 双击速度显示“快 · 150 ms”，不显示类型名。
- [ ] **POP-02** 恢复默认值宽约 450 px，无“推荐”。
- [ ] **POP-03** 配置管理宽约 450 px，删除为红色。
- [ ] **GEN-01** 通用页无登录运行、全屏暂停开关。
- [ ] **GEN-02** 应用排除圆角路径框，超过约 3 项内部细滚动条，移除为红色。

## 5. 性能

- [ ] **PERF-01** 无按键按下时位移定时器不空转。
- [ ] **PERF-02** 设置窗口进托盘后工作集明显下降。
- [ ] **PERF-03** 极速连拨滚轮约 20 秒，核心不退出。
